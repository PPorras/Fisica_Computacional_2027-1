# Unidad 03 — Módulos

## Temas
- **Python (Tutorial oficial, capítulo 6):**
  - Más sobre módulos
    - Ejecutar módulos como scripts
    - La ruta de búsqueda de módulos
    - Archivos "compilados" de Python
  - Módulos estándar
  - La función dir()
  - Paquetes
    - Importar todo (`*`) desde un paquete
    - Referencias dentro del propio paquete
    - Paquetes en múltiples directorios
- **Física computacional:** organizar el código del curso en módulos y
  en el paquete [`fiscomp/`](../../fiscomp/), en vez de tener todo en
  un solo script; usar `sys` y `math` (módulos estándar) y ver cómo
  se conecta con lo que se viene construyendo en `fiscomp` (por
  ejemplo, [`fiscomp.precision_numerica.EPS`](../../fiscomp/precision_numerica.py)).

## Contenido
- [`constantes_fisicas.py`](constantes_fisicas.py): módulo propio de
  ejemplo (constantes y una función), usado para mostrar cómo se
  importa un módulo escrito por uno mismo.
- [`modulos.py`](modulos.py): script principal con los ejemplos de
  todos los temas de esta unidad.
